## ¿Qué tenéis que hacer?

1. Investigar cómo se escribe un condicional (`if/else`) o un bucle (`for/while`) en vuestro lenguaje asignado.
2. Escribir un ejemplo. Podéis utilizar los ejemplos de abajo o inventar uno propio.
3. Crear un **repositorio en GitHub utilizando Git** y subir:
   - El archivo con vuestro código.
   - Un `README.md` con los nombres de los integrantes, el lenguaje asignado y las respuestas a estas preguntas:
     - ¿Cómo se declaran las variables?
     - ¿Cómo se delimitan los bloques de código?

**Todos los integrantes deberán saber explicar el código.** Haremos una breve puesta en común en clase.

## Ejemplos de referencia en Python

### Condicionales

```python
edad = 20

if edad >= 18:
    print("Mayor de edad")
else:
    print("Menor de edad")
```

### Bucles

Ejemplo: recorrer una lista y saludar a cada persona.

```python
nombres = ["Ana", "Pedro", "Lucía"]

for nombre in nombres:
    print("Hola", nombre)
```

Podéis utilizar `for` o `while` en vuestro lenguaje asignado.
